Harita hakkında ve güncelleme rehberi

Bu harita nedir?

İzmir'de İl Özel İdaresi'nden İzmir Büyükşehir Belediyesi'ne devredilen mahalle ve köy yollarının belirlenmesi çalışmasıdır. Yollar QGIS ortamında sınıflandırılır, bu site de o çalışmanın herkese açık görüntüsüdür. Çalışma sürmektedir; yollar ve sınıflandırmaları zaman içinde değişebilir.

Kategoriler ne anlama geliyor?

Haritayı nasıl kullanırım?

  • Soldaki kutucuklarla kategorileri açıp kapatabilirsiniz.
  • Kategorinin yanındaki ✎ ile adını ve çizgi rengini değiştirebilirsiniz. İlçe bölümündeki ✎ ile de sınır çizgisinin rengini, kalınlığını ve tipini ayarlayabilirsiniz.
  • Arama kutusuna yol adı yazıp sonuca tıklayınca harita o yola gider.
  • Bir yola tıklayınca adı, tipi, uzunluğu ve koordinatı görünür.
  • 📏 Mesafe ölç ile harita üzerinde çok noktalı mesafe ölçebilirsiniz.
  • Veriyi indir ile GeoJSON veya KML dosyasını bilgisayarınıza alabilirsiniz.

Veriyi güncellemek (çalışmayı yürüten kişi için)

  1. QGIS'te katmanı sağ tıklayın → Dışa Aktar → Özellikleri Farklı Kaydet… → biçim KML, dosya adı ibb_yollar.kml.
  2. GitHub deposunda veri klasörünü açın → Add file → Upload files.
  3. Yeni ibb_yollar.kml dosyasını sürükleyip Commit changes deyin.
  4. 2–3 dakika içinde bu site otomatik olarak yenilenir.

Kategori değişikliklerini herkes için kalıcı yapmak

Yaptığınız değişiklikler şu an yalnızca sizin tarayıcınızda saklı. Siteyi açan herkeste geçerli olması için veri/kategoriler.json dosyasının güncellenmesi gerekiyor. Aşağıdaki iki adım bunu yapar:

1. Aşağıdaki metni kopyalayın

2. GitHub'da dosyayı açıp yapıştırın

kategoriler.json dosyasını GitHub'da aç ✎ Depo bilgisi bulunamadı. GitHub deponuzda veri/kategoriler.json dosyasını açıp kalem simgesine tıklayın.

Açılan sayfada eski içeriğin tamamını silin, kopyaladığınız metni yapıştırın ve alttaki Commit changes düğmesine basın. 2–3 dakika içinde site herkes için güncellenir.
